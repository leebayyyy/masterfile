⌨️ GAISANO-STYLE POS TERMINAL HOTKEY CARD
Key / Shortcut Action Workflow Description
F1 Hotkey Help Open this quick reference guide and key bindings.
F2 Product Lookup Search products by barcode OR name. Navigate with ↑↓ and press Enter to add.
F3 Focus Quantity Jump to Quantity field. Type quantity → press Enter → scan barcode!
F4 Void Selected Line Item Removes highlighted item from cart. Requires Supervisor Override.
F5 Void Entire Transaction Discards active cart and clears register. Requires Supervisor Override.
F6 Cash Float (Change Fund) Add cash fund into register drawer. Requires Supervisor Override.
F7 Cash Lift / Pickup / Drop Remove excess cash from register drawer. Requires Supervisor Override.
F8 AR Credit Sale ("Utang") Switch to AR mode, verify credit limit eligibility, and open AR credit checkout.
F9 Checkout / Tender (Cash) Open cash tender payment screen with live change (sukli) calculator.
F10 Resume Held Sale View held carts and recall transaction. Requires Supervisor Override.
F11 Hold Transaction Park current transaction cart for next customer. Requires Supervisor Override.
F12 Complete Sale / Tender Finalize sale, print receipt, calculate change (sukli), and update balances.

Enter / Space Activate Focused Control Triggers the currently focused button, tab, lookup, void, or tender. Adds scanned item if on barcode input.
Esc Return Home / Close Modal Instantly returns focus to barcode input (home position) from any button, view, or modal without silent data loss.
